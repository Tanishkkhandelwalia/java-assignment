# Java OOP Projects

Two complete Java console projects demonstrating Object-Oriented Programming.

## Projects

1. **Q1 - Food Delivery Management System**
   - Regular and Premium orders
   - Discounts and delivery charges
   - Validation and billing
   - Static order counter

2. **Q2 - Smart Library Resource Management System**
   - Books and Digital Resources
   - Fine calculation
   - Resource validation
   - Static resource counter

## Concepts Demonstrated

- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
- Interfaces
- Method Overriding
- Constructors
- Static Members
- Packages
- Utility Classes
- Service Classes

## Requirements

Java JDK 8 or later.

Each project has its own README with compile and run commands.
